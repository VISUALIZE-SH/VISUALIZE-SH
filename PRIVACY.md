# Privacy

VISUALIZE-SH does not use analytics, advertising pixels, browser fingerprinting,
or tracking cookies. The site does not set cookies or store newsletter preferences
in the browser. It stores a single `localStorage` preference (`visualize-sh-theme`)
for the visitor's selected light, dark, or system color theme; it is not used for
analytics, advertising, or cross-site tracking. It does load its typefaces from Google Fonts; those network
requests are governed by Google's privacy terms, and VISUALIZE-SH does not receive
or use data from them. The hosting provider may process ordinary request logs as
part of serving the static site.

The newsletter button opens a separately hosted Zoho Campaigns subscription form.
The current demo form asks for an email address and name. Information entered there
is submitted directly to Zoho, which sends a confirmation email before the
subscription is complete. Subscriber addresses are not stored in this repository
or in the public newsletter pages.

Newsletter issues are public, static HTML. Do not include subscriber data,
recipient lists, private notes, credentials, or other sensitive information in an
issue or in the repository data files.

The published site notice is available at
[visualize-sh.com/privacy.html](https://visualize-sh.com/privacy.html).
