# Retired GitHub newsletter workflow

The GitHub-hosted research and delivery plan was replaced by the owner's local
scheduled research and local delivery approval. Follow
[`LOCAL_NEWSLETTER_WORKFLOW.md`](LOCAL_NEWSLETTER_WORKFLOW.md) and `ROUTINE.md`.

GitHub Actions still validates repository changes and deploys the public site to
Pages. It does not research the weekly issue, create a newsletter, or send a Zoho
campaign. Do not add an OpenAI API key or copy the private source watchlist into
GitHub for this workflow.
